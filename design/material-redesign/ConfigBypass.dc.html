Full bypass permissions mode

Full bypass mode: every tool request that would ask for approval is allowed without asking. Configured deny rules and managed policies still apply.

Use it only in a sandbox or on code you trust.

bypass_permissionsboolean · default off
Off: tools ask when a rule says ask
Default

What changes, and what does not

ask becomes allow. Calls that would stop for approval run straight away.
deny stays deny. Your configured deny rules still block.
Managed policies still apply. Limits set by an administrator are not bypassed.
