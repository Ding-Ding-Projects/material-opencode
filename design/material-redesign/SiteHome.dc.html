Everything the config file can do, without opening it.

A control for every setting

Switches, sliders, chips and pickers for every key in the config file. Each one shows where its value comes from and can be reset.

Permission rules you can read

Order allow, ask and deny rules by dragging. Test a command to see which rule decides before you save.

MCP servers without the JSON

Add a local or remote server, set its environment and headers, and watch its status change as it connects.

One palette for everything

Ctrl+Shift+F finds sessions, files, commands and settings, and lets you change a setting right in the results.

Runs as a web app in Docker

Host it on a machine you own and open it from any browser on your network. The first account becomes the owner.

Or as an appliance

A minimal image that boots straight into the web app and shows its address on screen. Flash it to a USB drive or a Raspberry Pi.

Three ways to run it

Desktop app

Install it and open a project folder. Nothing else to set up.

Download

Web app in Docker

One container on a machine you own. Open it from any browser on your network.

docker run -p 4096:4096 \
  -e OPENCODE_PASSWORD=[YOUR PASSWORD] \
  -v opencode-data:/data \
  -v "$PWD":/workspace \
  material-opencode
