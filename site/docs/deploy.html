Deploy desktop app

Targets

Deploy is a desktop app for Windows and Linux that sets up the web app or the appliance for you. Targets available now:

  • This computer (Docker): pulls the web app image and starts it with Compose.
  • Docker host over SSH: copies the Compose files to another machine and starts it there.
  • VirtualBox: downloads the appliance image, creates an EFI virtual machine with a forwarded port and starts it headless.
  • VMware: creates an EFI virtual machine from the appliance image with bridged networking and reads its address from the console.

Each target checks what it needs (Docker, SSH, VirtualBox, VMware) on your computer before you start. After starting, the app waits for the new instance to answer before it reports success.

Instance manager

The app keeps a record of every instance it created: name, target, version, port, address and last health check. It only starts, stops or removes instances in that record, and names never collide with ones it already made.

Bundled source

The app carries a snapshot of the repository's source inside it, with a checksum. If the published web app image cannot be pulled, or you ask to build from source, it builds the image from that bundle. Deploying never needs a separate download of the source.

USB drive and SD card flashing

The app can write the appliance to a USB drive for a spare PC, or to an SD card for a Raspberry Pi. These safeguards are built in:

  • Only removable disks are listed.
  • No disk is preselected.
  • A two-key confirmation names the disk before anything is written.
  • After writing, the app reads the disk back to verify it.

Writing an image erases everything on the chosen disk.

Get it

Download the portable Windows .exe or the Linux AppImage from the latest release.
