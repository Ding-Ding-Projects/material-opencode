Appliance image

What it is

The appliance is a minimal Alpine Linux image that boots straight into Docker and starts the app. The app image is already inside, so it works offline.

Images

  • x86_64 UEFI as a raw disk image, for USB drives and spare PCs.
  • x86_64 as a VDI for VirtualBox, with EFI turned on.
  • x86_64 as a VMDK for VMware Workstation.
  • Generic arm64 UEFI.
  • Raspberry Pi 4 and 400, with UEFI firmware on the boot partition.

Get them from the latest release. Each image has a checksum file.

Boot it

  1. In VirtualBox, import the VDI, turn on EFI (Settings › System) and use a bridged network. For hardware, write the raw image to a USB drive or SD card.
  2. Boot it. The console shows the address to open.
  3. Log in on the console as root and run material-opencode password to see the server password.

Commands

material-opencode password   # show the server password
material-opencode url        # show the address
material-opencode update     # pull the newest app image and restart
material-opencode logs       # follow the app log
