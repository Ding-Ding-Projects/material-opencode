Material chat

Composer

The message composer uses the Material look: a rounded field with pill buttons and the same focus and press motion as the rest of the app.

Message bubbles

Messages in a session are drawn as Material bubbles with tonal colours that follow your theme and light or dark mode. Some session side panels still keep their original layout.

Prompt starters

A new, empty session offers prompt starters. Choosing one fills the empty composer with that prompt so you can edit it before sending.
